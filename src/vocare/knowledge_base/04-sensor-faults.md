# Sensor Faults

## Weight sensors

Used to confirm dispense counts (see E02). Drift over time and with dust buildup; cleaning
(see cleaning procedures) resolves most gradual accuracy complaints. A sudden, large jump in
readings after no known event (no drop, no cleaning, no part swap) is unusual and should be
treated as a possible hardware fault rather than something to recalibrate away repeatedly.

## RFID canister readers

Used to identify which medication is loaded in each slot (see E01). Reader range is short by
design (a few millimeters) to avoid misreading a neighboring slot's canister - if a canister
"disappears" from the system only when a specific neighboring slot is also loaded, that's worth
reporting as a possible reader cross-talk issue, not just a seating problem.

## Pouch seal sensor

Confirms each pouch sealed correctly before it's released. If pouches are being released
unsealed or torn, stop using the unit and escalate immediately - this is a patient-safety issue,
not a routine troubleshooting item.

## Door/interlock sensors

The unit will not dispense with any access door open, by design. If the unit reports a door
open error while all doors are visibly closed, the interlock sensor itself may be misaligned -
this needs a technician, don't force or bypass an interlock.
